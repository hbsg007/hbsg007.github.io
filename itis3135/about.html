About

This course site demonstrates my work for ITIS3135 — Front-End Web Application Development at UNC Charlotte, taught by Professor D.I. von Briesen. The instructor's course website provides more information about the class, its assignments, and its standards.

The course builds practical experience in front-end web application development through several websites with different purposes. I use HTML, CSS, JavaScript, and a variety of development tools to practice organizing content, designing usable pages, checking accessibility, and publishing work on the web.

Tools Used in the Course

  • VS Code: editing and organizing website files.
  • Emmet within VS Code: writing common HTML structures efficiently.
  • SFTP through FileZilla: transferring files to Charlotte's webspace.
  • Git through GitHub Desktop and GitHub.com: tracking changes and publishing the GitHub Pages copy.
  • Browser tools: inspecting page structure, debugging scripts, and checking responsive layouts.
  • The Accumulus Validator: checking markup and reviewing accessibility results.
  • The Vicunadator: checking the course's structural and naming standards.

Sites and Projects

  • Personal home portfolio: a separate introduction to me and my interests, outside the course folder.
  • Course site: this collection of ITIS3135 assignments and exercises.
  • Design firm: Grewal Web Design, my fictional design and consulting brand.
  • CRAPpy page: an intentionally poorly designed page that demonstrates habits to avoid elsewhere.
  • Whimsical product company: a planned business site built around my mascot and a product idea.
  • Student, colleague, or peer management tool: a planned interactive tool for organizing information about people.
  • Client project website: a planned site developed around a client's needs.
  • Volleyball hobby site: my standalone site about learning and enjoying volleyball.
